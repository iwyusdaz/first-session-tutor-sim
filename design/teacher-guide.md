# Facilitator guide (for trainers and site coordinators)

For use after [`tutor-training-course`](https://github.com/iwyusdaz/tutor-training-course) Modules 2–3, before tutors work with real students. One run takes 20–30 minutes. Bridge Math Tutoring and all three students are fictional, constructed for teaching purposes.

## Before the session (5 min)

- Remind tutors of the five-part routine: warm-up 5′ → review 5′ → guided practice 12′ → independent try 5′ → exit ticket 3′.
- Name the seven canonical moves from [`socratic-ai-tutor`](https://github.com/iwyusdaz/socratic-ai-tutor): probing question; hint ladder (levels 0–5); wait time; specific feedback; worked example after repeated failure; confirm and ask why; offer a similar problem.
- Tell tutors the students are simulated with a simple, transparent rule model. The point is the reasoning behind each move, not "beating" the model.
- Have tutors set the wait-time scale or manual wait in "1. Before you start" if they need more processing time.

## Run 1: the quiet student (15–20 min)

Tutors play alone or in pairs (one drives, one notices). Encourage them to use the optional "Notice" checklist at every moment.

## Debrief (10–15 min)

Open the replay together. Suggested prompts:

1. At moment 3 (the error), what did you say? What happened to that student's understanding line?
2. At moment 4, did you wait? What did Talia do?
3. Which cues did you notice that mattered? Which did you mark that didn't?
4. Which rubric domain scored lowest? Find the moment that caused it.
5. What would you do differently at moment 4?

The coach notes are written for the debrief. They are not feedback from a real coach.

## Run 2: the dominant student (transfer)

Same session, different mix: Jordan fills every silence and Sam makes the first error. Ask tutors to predict which moves will matter most before they play.

## Using it for coaching

The debrief timeline and score table give a shared reference for a coaching conversation that mirrors the observation rubric. Treat scores as conversation starters. They are not a certification and say nothing about how a tutor performs with real students.

## Limits to say out loud

- The rule model is simplified. Real students vary far more.
- Text descriptions of cues make noticing easier than real life.
- Nothing here has been tested with real tutors yet.
